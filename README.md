# Amina Saif — Portfolio

Static portfolio site published with GitHub Pages at <https://raiamna0.github.io>.

## Files

- `index.html` — portfolio page
- `cv.pdf` — downloadable CV linked from the page
- `.nojekyll` — serve the site as static files without Jekyll processing

## Publishing

GitHub Pages deploys the root of the `main` branch. Changes pushed to `main` are published automatically.

To update the CV, replace `cv.pdf` with a new file of the same name.
